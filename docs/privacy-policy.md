Pop is a local macOS screenshot and annotation utility. Pop does not collect,
track, sell, rent, or share personal data.

## Data Collection

Pop does not collect data from users. Pop does not include analytics,
advertising, telemetry, account login, remote sync, or crash-reporting SDKs.

## Screen Capture And OCR

Pop uses macOS Screen Recording permission so the user can capture screenshots.
Captured images are processed locally on the user's Mac for annotation, copying,
saving, and optional OCR.

The OCR feature uses Apple's on-device Vision framework. Pop does not upload
screenshots or recognized text to a server.

## Clipboard And Local Files

Pop can copy screenshots or recognized text to the local macOS pasteboard.

If the user enables local saving, Pop writes PNG files only to a directory the
user selects through the macOS open panel. Pop stores the selected directory
permission using a macOS security-scoped bookmark so saving continues to work in
the app sandbox.

## Network Use

Pop does not send screenshot content, OCR content, clipboard content, settings,
or usage data over the network.
